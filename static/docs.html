Getting Started

Our REST API provides predictable, resource-oriented URLs and uses standard HTTP verbs, authentication, and responses.

Authentication

Authenticate your account by including your secret API key in the request header.

Authorization: Bearer YOUR_API_KEY

Endpoints

List Jobs

Retrieve a paginated list of normalized job data.

GET /api/v1/jobs?skip=0&limit=50

List Sources

Get the health status and configurations of all active source adapters.

GET /api/v1/sources

Trigger Ingestion

Manually trigger a sync for a specific source.

POST /api/v1/ingest/{source_name}

Rate Limits

Rate limits are enforced at the network edge based on your pricing tier. Standard tier defaults to 1,000 requests per IP address per day.
