Getting Started

Our REST API provides predictable, resource-oriented URLs and uses standard HTTP verbs, authentication, and responses. Responses are returned in structured JSON formats mapped directly from our normalization engine.

Authentication

Authenticate your account by including your secret API key in the request header. If a request is missing an API key, or if the API key is invalid, the API will return a 401 Unauthorized status code.

Authorization: Bearer YOUR_API_KEY

Endpoints

Jobs API

List Jobs
Retrieve a paginated list of normalized job data across all sources. You can optionally filter by remote status or a specific source ID.

GET /api/v1/jobs/?skip=0&limit=20&remote_only=false

Get Single Job
Retrieve the complete payload for a specific job entry by its UUID.

GET /api/v1/jobs/{job_id}

Export Jobs (JSON/CSV)
Download the entire active job dataset in bulk formatting.

GET /api/v1/jobs/export/json
GET /api/v1/jobs/export/csv

Sources API

List Sources & Health
Get the health status, configurations, and latency metrics of all active source adapters.

GET /api/v1/sources/

View Activity Logs
Fetch the latest 10 scraping run logs detailing status, duration, and error messages (e.g., HTTP 429 warnings).

GET /api/v1/sources/logs

Ingestion API

Trigger Manual Sync
Manually trigger a pipeline sync for a specific source adapter. This bypasses the scheduler, executes synchronously, and returns the ingestion metrics (e.g., new jobs vs updated jobs).

POST /api/v1/ingest/{source_name}

Rate Limits

Rate limits are enforced at the network edge based on your account quota. The standard integration tier defaults to 10,000 requests per IP address per day. Exceeding this limit will result in a 429 Too Many Requests response.
